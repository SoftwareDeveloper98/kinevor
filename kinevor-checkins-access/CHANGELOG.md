## [0.1.0] - 2026-10-20

### Added

- Standalone check-ins backend with club branches, access member projections,
  visits and append-only audit records, MediatR queries and workflows, EF Core
  persistence, SQLite demo host and platform authorization policies.
- Server-side access policy for member state, membership state and date window,
  home-club restrictions and all-club access, with explainable reason codes.
- Front-desk member search, eligibility, check-in, check-out, duplicate-visit
  protection, live occupancy, daily statistics and filtered visit history.
- Member self-service status, check-in, check-out, monthly summary and visit
  history scoped to the authenticated member.
- Angular library with front-desk, occupancy and visit-history screens, typed
  HTTP gateway, signal facades, providers and routes.
- Angular demo application with the Kinevor visual system, Sora typography,
  Material icons and local development identity.
- Flutter package with API client, repository, check-in and visit-history
  screens, theme, strings and a runnable example application.
- Real web, mobile and Swagger screenshots under `docs/screenshots`.
- NuGet packing, GitHub Actions CI and tag-based release workflows.
- MIT license and package documentation.
